# Робот-боксёр v3 «Горилла» — концепция и размеры (2026-11-14)

Задание пользователя: свой вариант с нуля на MG90S; ходит во все стороны, встаёт после падений, приёмы боя,
вид устрашающий, сборка как конструктор (втулки, защёлки, печать). v2 заморожена.

## Уроки v2 → требования
| Проблема v2 | Решение v3 |
|---|---|
| Крен бедра 85–95 % stall (ось в 26 мм от ЦМ) | ось крена над стопой (y 18,5 при центре стопы 24) → статический момент ≈ 0 |
| Не встаёт: плечо ±90° только к ногам, нога не складывается, торс 87 мм | колено до 125°, бедро до 130° вперёд, низкий голеностоп, длинные руки (≈140 мм) достают пол в приседе |
| Узел J2 = 45 мм на каждый сустав, оси не пересекаются | X-блок: две сервы крест-накрест в одном корпусе, оси в 15 мм |
| Нет поворота на месте | рыскание бедра (2 сервы), пояс не нужен: доворот корпуса для удара дают они же |

## Кинематика: 18 × MG90S
- Нога (6): рыскание, крен, тангаж бедра, колено, тангаж и крен голеностопа.
- Рука (3): плечо (тангаж), отведение (крен), локоть.

Система робота: x вниз, y влево, z вперёд, мм. Начало — на оси тангажа бедра, по центру.

| Ось | Положение (левая сторона) |
|---|---|
| Рыскание бедра | вдоль x, y 24, z 0; блок x −71,7…−37,3 (в торсе, вал вниз) |
| Крен бедра | вдоль z, x −15, y 18,5 |
| Тангаж бедра | вдоль y, x 0, z 0 |
| Колено | вдоль y, x 46 |
| Тангаж голеностопа | вдоль y, x 92 |
| Крен голеностопа | вдоль z, x 107, y 18,5 |
| Подошва | x 124 (85 × 44 мм, центр y 24) |
| Плечо | вдоль y, x −85, z 0; блок снаружи торса, y 45,8…80,2 |
| Отведение руки | вдоль z, x −59,4, y 64,5 |
| Локоть | вдоль y, x −19,2 |
| Кулак (торец) | x ≈ +56 при опущенной руке |

Рост ≈ 241 мм (подошва 124, верх торса −95, голова до −117), ширина по плечам ≈ 162 мм.

## Серво-блок (единый модуль)
В системе сервы (ось вала s, длина l, толщина t): тело l ±11,5, t ±6,125, s −11,9…12; ушки s 5,15…7,65, l ±16,12;
бобышка до 16,03; вал до 19,9; качалка s 19,3…20,9.
- Гнездо в теле звена: l ±11,6, t ±6,5, s −12,1…5,15 (ушки лежат на кромке). Дно 3,3 мм с глухим отверстием Ø6,3×2,6
  под палец. Габарит блока: l ±16,4, t ±8,1, s −15,4…19,0 (34,4).
- **Крышка** (общая, 18 шт.): s 5,15…19,0, два штыря Ø2,8 сквозь отверстия ушек в тело; отверстие Ø7,6 под ступицу качалки.
- **Вилка**: щека A (со стороны вала) s 19,3…22,5 со сквозным карманом по форме качалки (замкнутый контур), щека B
  s −18,7…−15,7 с отверстием Ø5,9.
- **Палец** Ø6 с головкой Ø10 — вставляется снаружи через щеку B (плотно) в отверстие блока Ø6,3 (свободно).
- **Заглушка качалки** — вставляется снаружи в карман щеки A, держит качалку.
- Зазор вращения 0,3 мм. Винтов нет; все оси в замкнутых отверстиях.
